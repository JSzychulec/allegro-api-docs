Allegro Account Manager

Dokumentacja planowanej aplikacji korzystającej z Allegro REST API — aktualizacja 18 listopada 2026 r.

Projekt jest prywatnym narzędziem do obsługi własnego konta Allegro. Nie jest udostępniany innym sprzedawcom ani klientom jako usługa. Dokument opisuje planowane możliwości; ich uruchomienie zależy od wdrożenia, testów i przyznanych uprawnień.

1. Cel aplikacji

Usprawnienie pracy właściciela konta sprzedażowego Allegro: analiza danych oraz wykonywanie zatwierdzonych operacji za pośrednictwem oficjalnego Allegro REST API. Nowa aplikacja będzie odrębna od istniejącej integracji z systemem fakturowym.

2. Planowane funkcjonalności

  • Przeglądanie, tworzenie i edycja ofert, cen, parametrów, stanów magazynowych i ustawień sprzedaży.
  • Obsługa zamówień, przesyłek, etykiet i odbiorów kurierskich.
  • Odczyt oraz obsługa wiadomości, ocen, komentarzy i dyskusji.
  • Odczyt salda, opłat, historii płatności i danych własnego profilu.
  • Obsługa zgłoszeń do kampanii, programów specjalnych i oznaczeń ofert.
  • Odczyt i zarządzanie danymi programu afiliacyjnego w zakresie dostępnym dla konta.
  • Wyszukiwanie i analiza danych produktów i katalogu w granicach dostępnych zasobów API.

Aplikacja nie będzie zmieniać danych osobowych profilu, wykonywać zwrotów pieniędzy, składać ofert kupna w licytacjach, korzystać z One Fulfillment ani ze starego zakresu Allegro Ads. Odczyt historii płatności, w tym informacji o istniejących zwrotach, pozostaje dostępny.

3. Integracja i autoryzacja

Integracja wykorzysta oficjalne Allegro REST API oraz OAuth 2.0 Authorization Code flow. Właściciel zaloguje się i udzieli zgody bezpośrednio na stronie Allegro. Aplikacja będzie sprawdzać parametr state i korzystać z PKCE oraz zarejestrowanego adresu przekierowania HTTPS. Tokeny będą uzyskiwane po stronie serwera i automatycznie odświeżane; dostęp i odświeżanie będą ograniczone do zatwierdzonego konta.

Planowane wdrożenie: bezstanowy serwer MCP w Node.js na AWS Lambda, endpoint HTTPS i oddzielna autoryzacja klientów ChatGPT/Claude. Tokeny Allegro będą przechowywane trwale w szyfrowanej tabeli DynamoDB, a sekret aplikacji w AWS Secrets Manager. Role IAM będą ograniczone do wymaganych zasobów. Tokeny, sekrety i dane klientów nie będą publikowane w dokumentacji ani zapisywane w logach aplikacji. Sklep WooCommerce pozostaje na osobnym hostingu.

4. Zakres uprawnień

Wniosek obejmuje wyłącznie następujące 17 zakresów:

  • allegro:api:sale:offers:read
  • allegro:api:sale:offers:write
  • allegro:api:sale:settings:read
  • allegro:api:sale:settings:write
  • allegro:api:campaigns
  • allegro:api:orders:read
  • allegro:api:orders:write
  • allegro:api:ratings
  • allegro:api:disputes
  • allegro:api:billing:read
  • allegro:api:payments:read
  • allegro:api:profile:read
  • allegro:api:messaging
  • allegro:api:shipments:read
  • allegro:api:shipments:write
  • allegro:api:affiliate:read
  • allegro:api:affiliate:write

Wykluczone zakresy: allegro:api:profile:write, allegro:api:payments:write, allegro:api:bids, allegro:api:fulfillment:read, allegro:api:fulfillment:write, allegro:api:ads. Nie będą żądane przy autoryzacji ani udostępniane przez narzędzia MCP.

5. Sposób korzystania z API i kontrola użytkownika

Serwer udostępni wyłącznie jawnie zdefiniowane operacje i będzie respektować zakresy OAuth oraz limity Allegro. Operacje zmieniające oferty, ceny, zamówienia, ustawienia sprzedaży, wiadomości, przesyłki lub uczestnictwo w płatnych programach będą wykonywane po zatwierdzeniu konkretnej operacji przez właściciela. Dostęp do funkcji zapisu nie oznacza zgody na samodzielne wykonywanie dowolnych zmian przez model.

Żądania API będą identyfikowane nagłówkiem User-Agent zgodnym z aktualnymi wymaganiami Allegro, z identyfikatorem tej aplikacji. Obecna integracja fakturowa zachowa własną rejestrację i konfigurację.

6. Przykładowe zasoby API

  • /sale/offers — odczyt ofert.
  • /order/checkout-forms — pobieranie zamówień.
  • /sale/products — dane katalogu produktów zgodnie z dostępnymi metodami.

Lista jest orientacyjna; konkretne metody zostaną sprawdzone przy implementacji. Pełny katalog zasobów: dokumentacja Allegro REST API.

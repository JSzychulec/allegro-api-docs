Narzędzie do zarządzania kontem Allegro

Dokumentacja planowanej aplikacji korzystającej z Allegro REST API

Projekt jest prywatnym narzędziem do obsługi własnego konta Allegro. Nie jest udostępniany innym sprzedawcom ani klientom jako usługa. Zakres opisuje planowane możliwości; ich wdrożenie zależy od przyznanych uprawnień.

1. Cel aplikacji

Usprawnienie pracy właściciela konta sprzedażowego Allegro za pomocą narzędzia. Aplikacja będzie umożliwiać odczytywanie i analizowanie danych oraz wykonywanie wybranych operacji na własnym koncie za pośrednictwem oficjalnego Allegro REST API.

2. Planowane funkcjonalności

  • Przeglądanie i analiza własnych ofert, cen, parametrów i stanów magazynowych.
  • Przeglądanie zamówień i danych potrzebnych do ich obsługi.
  • Analiza sprzedaży, statystyk i dostępnych danych rozliczeniowych.
  • Przygotowywanie propozycji zmian ofert i cen, a po zatwierdzeniu przez użytkownika — wykonywanie dozwolonych operacji.
  • Wyszukiwanie i analizowanie danych produktów i katalogu w granicach dostępnych zasobów API.
  • Obsługa innych funkcji Allegro REST API, jeśli są potrzebne do pracy z własnym kontem i zostały udostępnione aplikacji.

3. Integracja i autoryzacja

Integracja wykorzysta oficjalne Allegro REST API oraz OAuth 2.0. Użytkownik autoryzuje aplikację na własnym koncie. Żądania będą wykonywane w granicach przyznanych zakresów uprawnień i limitów API. Tokeny i dane uwierzytelniające będą przechowywane poza publiczną dokumentacją i kodem strony.

4. Zakres uprawnień

Planowane są uprawnienia do odczytu i, tam gdzie niezbędne, modyfikacji zasobów związanych z ofertami, zamówieniami, produktami oraz rozliczeniami. Konkretne zakresy OAuth zostaną dobrane do wdrażanych funkcji; aplikacja nie zakłada nieograniczonego dostępu poza uprawnieniami udzielonymi przez Allegro i użytkownika.

5. Przykładowe zasoby API

  • /sale/offers — zarządzanie ofertami.
  • /order/checkout-forms — pobieranie zamówień.
  • /sale/products — dane katalogu produktów (zgodnie z dostępnymi metodami).

Lista jest orientacyjna i będzie aktualizowana wraz z implementacją. Pełny katalog zasobów: dokumentacja Allegro REST API.

6. Sposób korzystania z API

Aplikacja jest przeznaczona do użytku własnego. Komunikacja z Allegro REST API będzie realizowana przez OAuth 2.0, w zakresie uprawnień udzielonych aplikacji. Zakres wykorzystywanych endpointów będzie zależał od wdrożonych funkcji.

Dokumentacja aplikacji wewnętrznej. Nie jest to oficjalna dokumentacja Allegro ani aplikacja powiązana z Allegro sp. z o.o.
